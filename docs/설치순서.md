# 쿨린 일정 위젯 설치 순서

쪽지에서 일정을 뽑아 바탕화면에 띄워 주는 프로그램입니다.
**파이썬도 Node 도 따로 깔지 않습니다.** 설치 파일 하나면 됩니다.

---

## 1. 설치

1. `쿨린위젯_설치.exe` 를 더블클릭합니다.
2. 「Windows의 PC 보호」 창이 뜨면 **[추가 정보] → [실행]** 을 누릅니다.
   (그냥 닫으면 설치가 되지 않습니다.)
3. 처음 설치할 때 화면에 필요한 구성 요소(WebView2)를 자동으로 받습니다. 1~2분 걸릴 수 있습니다.
4. 설치가 끝나면 화면 오른쪽 위에 위젯이 뜹니다. 바탕화면에도 아이콘이 생깁니다.

설치는 **내 계정에만** 됩니다. 관리자 권한이 필요 없고, 다른 사용자 계정은 건드리지 않습니다.

## 2. 처음 한 번

- 위젯 오른쪽 위 **[부팅 시 자동 실행]** 이 켜져 있으면, 컴퓨터를 켤 때마다 위젯이 함께 뜹니다.
  끄고 싶으면 그 단추를 다시 누르면 됩니다. 한 번 끄면 다시 켜지지 않습니다.

## 3. 쪽지 가져오기

1. **쿨메신저를 먼저 켜 둡니다.** (로그인까지)
2. 위젯의 **[가져오기]** 를 누릅니다.
3. 위젯이 잠깐 숨고, 쿨메신저 창이 앞으로 나와 스스로 움직입니다. **그동안 마우스·키보드를 건드리지 마세요.**
4. 10초쯤 뒤 위젯이 돌아오고 일정이 채워집니다.

기간을 정해 받고 싶으면 위젯의 날짜 칸에 `20260828` 처럼 **여덟 자리**로 적고 [기간 정리] 를 누릅니다.

### 가져오기가 안 될 때

| 나오는 말 | 할 일 |
| --- | --- |
| 다운로드 창을 열지 못했습니다 | 쿨메신저가 다른 창에 가려져 있지 않은지 보고 다시 누릅니다 |
| 날짜 칸을 누르지 못했습니다 | 같은 이유입니다. 쿨메신저를 한 번 클릭해 앞으로 꺼낸 뒤 다시 누릅니다 |
| 내려받은 쪽지의 날짜가 기간을 벗어났습니다 | 기간이 잘못 들어간 것입니다. 다시 누르면 됩니다 — **틀린 파일을 쓰지 않고 멈춥니다** |

## 4. 일정 보기

- **일정** — 자동으로 등록해도 될 만큼 확실한 것만 캘린더에 들어갑니다.
- **검토** — 확신이 부족한 것입니다. 확인하고 [캘린더에 반영] 을 누르면 넘어갑니다.
- **할 일** — 체크하며 지워 나갑니다.
- 일정을 두 번 누르면 **어느 쪽지에서 나왔는지** 원문이 뜹니다.
- 별표를 단 일정은 캘린더에서 빨간 글씨·노란 음영으로 보입니다.
- **[구글 캘린더]** 를 누르면 기본 브라우저에서 등록 화면이 열립니다.

## 로컬 AI (선택 — 없어도 다 됩니다)

위의 모든 기능은 설치만으로 됩니다. **Ollama 는 안 깔아도 됩니다.**

깔면 규칙 엔진이 놓친 일정 후보를 하나 더 얹어 주고, 쪽지 요약·답장 초안을 써 줍니다.

1. <https://ollama.com> 에서 받아 설치합니다.
2. 명령 프롬프트에서 `ollama pull qwen2.5:3b`
3. 위젯의 AI 설정에서 [연결 시험] 을 눌러 모델이 보이면 끝입니다.

**쪽지 원문은 모델에도 가지 않습니다.** 이름·전화·이메일·주민번호·학번은 위젯이
먼저 `PERSON_1` 같은 토큰으로 바꾼 뒤에야 넘깁니다. 그 통신도 이 PC 안
(`localhost`)에서만 이뤄지며, 다른 주소로는 아예 보내지 않습니다.
