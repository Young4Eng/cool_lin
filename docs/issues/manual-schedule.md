# 일정 정리 수동화 기능

교사가 **원할 때** 기간을 지정해 일정 정리를 바로 돌릴 수 있게 한다. 어제~오늘만이 아니라, 지난 주나 특정 하루처럼 필요한 구간을 직접 고른다.

## 왜 필요한가

자동 예약은 「매일 같은 시각」에 맞춘다. 방학 직전 쪽지를 다시 보거나, 특정 공문 기간만 다시 정리하려면 **지금, 이 기간으로** 실행하는 입구가 따로 있어야 한다. 기간을 글자로 대충 넣으면 메신저가 엉뚱한 달을 내려받으므로, 형식을 분명하게 받는다.

## 누가 쓰는가

- 방금 받은 쪽지 구간을 바로 일정으로 만들고 싶은 교사
- 이미 지난 날짜의 쪽지를 다시 모아 캘린더를 보완하려는 교사

## 원하는 동작

1. 일정 정리 화면에 **수동 실행** 입구가 있다.
2. 기간은 **8자리 년월일(YYYYMMDD)** 로 적는다. 이 앱의 쿨메신저 내려받기는 시작 날짜와 끝 날짜가 있는 구간을 쓰므로, **시작과 끝 둘 다** YYYYMMDD 로 받는다. (예: `20260801` ~ `20260828`)
3. 8자리가 아니거나, 달력에 없는 날짜이거나, 시작이 끝보다 늦으면 **추출을 호출하지 않고** 한국어로 무엇이 잘못됐는지 보여 준다.
4. 기간이 맞으면 기존 쿨메신저 XLS 내려받기 → 일정 추출·정리 흐름으로 그 구간을 반영한다. 규칙을 새로 만들지 않는다.

## 완료로 보는 기준

- [ ] 수동 요청 시 시작·끝 YYYYMMDD 입력칸이 있다
- [ ] 잘못된 형식이면 안내만 나오고, 쿨메신저 조작·추출이 시작되지 않는다
- [ ] 유효한 기간이면 해당 구간의 XLS를 받아 일정 정리가 돌아간다

## 하지 않는 일

- 하이픈 날짜(`2026-08-28`)나 자연어(「지난주」)를 몰래 추측해 변환하기
- 추출 규칙을 화면이나 서버에 한 벌 더 두기
