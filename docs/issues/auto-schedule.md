# 일정 정리 자동화 기능

쿨메신저 일정 정리 프로그램을 켜 둔 교사가, **미리 정해 둔 시각**에 일정 정리를 돌릴 수 있게 한다. 다만 쪽지를 꺼내거나 일정을 정리하는 일은 **반드시 한 번 확인한 뒤에만** 시작한다.

## 왜 필요한가

매일 같은 시각에 쪽지를 모아 일정을 맞추는 일은 반복 업무다. 그렇다고 눈에 보이지 않게 메신저를 조작하고 파일을 열면, 교사가 자리를 비운 사이 창이 바뀌거나 예상과 다른 기간이 내려받아질 수 있다. 시각은 기억해 두되, **실행 순간에 한 번 물어보는 것**이 학교 PC에서 안전한 기본값이다.

## 누가 쓰는가

- 일과 후(예: 17:00)나 아침 조회 전에 쪽지를 모아 두고 싶은 담임·교과 교사
- 요일마다 다른 시각이 필요한 교사 (월·수만, 평일만 등)

## 원하는 동작

1. 설정 화면에서 **행을 추가**해 자동 정리 시각을 여러 개 등록할 수 있다. 각 행에는 시각과 함께 사용할지 여부, 적용 요일 같은 관련 체크를 둔다.
2. 설정은 프로그램을 종료했다가 다시 켜도 그대로다.
3. 등록한 시각이 되면 일정 정리를 **바로 시작하지 않는다.** 「지금 일정을 정리할까요?」처럼 실행 여부를 묻는다.
4. **동의하면** 지금과 같은 쿨메신저 내려받기 → 일정 추출·정리 흐름으로 어제~오늘 쪽지를 반영한다. 추출 규칙을 새로 만들지 않는다.
5. **거부하거나 창을 닫으면** 이번 회차만 건너뛴다. 프로그램이 죽거나, 같은 시각을 초 단위로 계속 물어보면 안 된다.
6. 한 시각(슬롯)에 대해 답을 한 뒤에는 그 회차를 다시 묻지 않는다.

## 완료로 보는 기준

- [ ] 설정에서 시각 행을 추가·수정·삭제할 수 있고, 재시작 후에도 남는다
- [ ] 해당 시각에 확인 창이 뜬다
- [ ] 확인을 눌러야만 XLS 추출과 일정 정리가 돌아간다
- [ ] 건너뛰기를 눌러도 오류 없이 끝나고, 같은 슬롯을 바로 다시 묻지 않는다
- [ ] 확인 없이 조용히 추출·정리가 시작되지 않는다

## 하지 않는 일

- 확인을 생략하는 「완전 자동」 스위치
- 추출 규칙을 일정 엔진 밖에 한 벌 더 두는 일
- 쿨메신저 로그인·비밀번호를 저장하거나 입력하는 일
